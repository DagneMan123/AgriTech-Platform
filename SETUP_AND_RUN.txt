IF EMAIL DOESN'T ARRIVE

Problem: Email not in inbox or spam
─────────────────────────────────────
  1. Check spam/promotions folder
  2. Verify email configuration: php artisan tinker
     >>> config('mail.host')    # Should show: smtp.gmail.com
     >>> config('mail.port')    # Should show: 587
  3. Check logs: tail -50 storage/logs/laravel.log
  4. Try with retry: php artisan test:password-reset-email email@domain.com --retry

Problem: Gmail app password not working
──────────────────────────────────────
  1. Get Gmail App Password:
     - Go to: https://myaccount.google.com/apppasswords
     - Select: Mail + Windows Computer
     - Google generates 16-character password
  2. Update .env: MAIL_PASSWORD=xxxx xxxx xxxx xxxx
  3. Run: php artisan config:cache
  4. Try again: php artisan test:password-reset-email any@email.com

Problem: Port 587 blocked
────────────────────────
  1. Try port 465 instead:
     - Update .env: MAIL_PORT=465
     - Update .env: MAIL_ENCRYPTION=ssl
  2. Run: php artisan config:cache
  3. Try again: php artisan test:password-reset-email any@email.com
