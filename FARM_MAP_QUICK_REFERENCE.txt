FEATURE OVERVIEW
================================================================================
The Farm Map is an interactive mapping interface that allows farmers to 
visualize their farms geographically, manage farm locations, and access 
detailed farm information.

KEY COMPONENTS IMPLEMENTED
================================================================================

1. FarmMapView.vue (Main Page)
   ├─ Interactive Leaflet-based map
   ├─ Responsive layout (desktop/tablet/mobile)
   ├─ Error handling and loading states
   ├─ Farm selection and filtering
   └─ Detailed information modal

2. MapControls.vue (Control Panel)
   ├─ Farm selection dropdown
   ├─ Display options (boundaries, coordinates)
   ├─ Map type selector (street/satellite/terrain)
   ├─ Action buttons (zoom, details, download, refresh)
   └─ Farm information display

3. useMap.ts (Composable)
   ├─ Leaflet map initialization
   ├─ Marker management
   ├─ Layer control
   ├─ Location navigation
   └─ Cleanup and lifecycle

MAP TYPES
================================================================================

1. Street Map (Default)
   Provider: OpenStreetMap (OSM)
   URL: https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
   Attribution: © OpenStreetMap contributors
   Best For: Location reference, roads, basic geography
   Performance: Very good
   Updates: Frequent

2. Satellite Map
   Provider: ESRI World Imagery
   URL: https://server.arcgisonline.com/ArcGIS/rest/services/
         World_Imagery/MapServer/tile/{z}/{y}/{x}
   Attribution: Tiles © Esri
   Best For: Seeing actual farm terrain
   Performance: Good
   Updates: Daily/Weekly

3. Terrain Map
   Provider: ESRI World Topo Map
   URL: https://server.arcgisonline.com/ArcGIS/rest/services/
         World_Topo_Map/MapServer/tile/{z}/{y}/{x}
   Attribution: Tiles © Esri
   Best For: Understanding elevation and slopes
   Performance: Good
   Updates: Less frequently

ZOOM LEVELS REFERENCE
================================================================================

Zoom 0-3:    World view - see countries
Zoom 4-6:    Continental view - see all farms in region
Zoom 7-10:   Regional view - see multiple farms
Zoom 11-13:  District view - see individual farms clearly (Default: 6)
Zoom 14-16:  Farm view - see farm details, roads
Zoom 17-19:  Street view - see buildings, structures

1. Farm boundaries use circular approximation (not real polygons)
2. No real-time update notifications
3. No offline map support
4. No marker clustering (works fine with <50 farms)
5. Export only available as PNG (no PDF)
6. No drawing/editing tools for boundaries
7. Weather data not integrated yet
8. No historical farm data comparison

TROUBLESHOOTING GUIDE
================================================================================

Problem: Map appears blank
Solution: 
- Check browser console for errors (F12)
- Verify Leaflet CDN is loaded
- Ensure #farm-map element exists
- Check internet connection

Problem: Farms not showing on map
Solution:
- Verify farms have GPS coordinates
- Check API is returning farm data (Network tab)
- Try refreshing page
- Check browser console for errors

Problem: Map very slow
Solution:
- Switch to Street map (faster than Satellite)
- Disable "Show Coordinates" option
- Close other browser tabs
- Clear browser cache (Ctrl+Shift+Delete)

Problem: Marker in wrong location
Solution:
- Verify GPS coordinates in farm details
- Update coordinates with correct values
- Coordinate format: latitude, longitude
- Use 6+ decimal places for accuracy

Problem: Modal not opening
Solution:
- Click "View Details" button
- Wait for modal to load (may take 1-2 seconds)
- Check browser console for errors
- Try refreshing page
