================================================================================
                         API SPECIFICATION
================================================================================

ENDPOINTS PROVIDED:

1. LIST HARVESTS
   GET /api/farmer/harvests
   Returns: Paginated list of all harvests for authenticated farmer

2. CREATE HARVEST
   POST /api/farmer/harvests
   Body: {crop_id, harvest_date, quantity, unit, quality_grade, notes}
   Returns: Created harvest record (201 Created)

3. GET HARVEST
   GET /api/farmer/harvests/{id}
   Returns: Single harvest details with relationships

4. UPDATE HARVEST
   PUT /api/farmer/harvests/{id}
   Body: {fields to update}
   Returns: Updated harvest record

5. DELETE HARVEST
   DELETE /api/farmer/harvests/{id}
   Returns: Success message

6. HARVEST STATISTICS
   GET /api/farmer/harvests/statistics?year=2026
   Returns: Statistics for the specified year

AUTHENTICATION:
✅ Bearer token required in Authorization header
✅ All endpoints protected

VALIDATION:
✅ crop_id: Required, must exist in crops table
✅ harvest_date: Required, valid date
✅ quantity: Required, numeric, minimum 0.01
✅ unit: Required, one of (kg, tonnes, bags, liters)
✅ quality_grade: Optional, one of (excellent, good, fair, poor)
✅ notes: Optional, text
