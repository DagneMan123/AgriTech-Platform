================================================================================
                    QUICK FIX: Empty Crop Dropdown
================================================================================

PROBLEM:
The "Select Crop" dropdown in Harvest Management is empty.

FASTEST FIX (5 MINUTES):
================================================================================

1. CHECK IF YOU HAVE FARMS
   Go to: Farmer Dashboard → Farm Management → My Farms
   Do you see any farms listed?
   
   NO → CREATE A FARM
   YES → Go to Step 2

2. CHECK IF YOU HAVE CROPS  
   Go to: Farmer Dashboard → Farm Management → Crops
   Do you see any crops listed?
   
   NO → CREATE A CROP
   YES → Go to Step 3

3. CHECK CROP STATUS
   Look at your crops - what status do they have?
   
   Status should be ONE OF:
   ✓ growing
   ✓ ready_for_harvest
   ✓ planted
   
   Different status (like "planning" or "harvested") → EDIT CROP & CHANGE STATUS

4. TRY HARVEST PAGE AGAIN
   Go back to Harvests
   Click "Record Harvest"
   Crop dropdown should now show your crop!

================================================================================
                        HOW TO CREATE TEST DATA
================================================================================

STEP 1: Create a Farm
1. Go to "My Farms"
2. Click "Add Farm" button
3. Fill in:
   - Name: "Test Farm"
   - Location: Select any
   - Area: 5 hectares
4. Click "Save"
5. Wait for success message

STEP 2: Create a Crop
1. Go to "Crops"
2. Click "Add Crop" button
3. Fill in:
   - Farm: Select "Test Farm" (the one you just created)
   - Crop Type: "Wheat"
   - Variety: "Local"
   - Planting Date: Pick a date 30 days ago
   - Status: IMPORTANT! Set to "growing" ← THIS IS KEY
   - Area: 2 hectares
4. Click "Save"
5. Wait for success message

STEP 3: Try Recording Harvest
1. Go to Harvest Management
2. Click "Record Harvest"
3. You should now see: "Wheat - Local (Test Farm)" in dropdown
4. Select it
5. Fill in:
   - Harvest Date: Today
   - Quantity: 100
   - Unit: kg
   - Quality: excellent
6. Click "Record Harvest"
7. Success! Harvest appears in table

================================================================================
                         COMMON PROBLEMS
================================================================================

PROBLEM 1: "I see farms but no crops in dropdown"
→ CAUSE: You haven't created any crops yet
→ FIX: Create a crop (see above)

PROBLEM 2: "I see crops in Crops page but not in harvest dropdown"
→ CAUSE: Crop status is not "growing" or "ready_for_harvest"
→ FIX: Edit the crop and change status to "growing"

PROBLEM 3: "I don't see any farms"
→ CAUSE: No farms created for your account
→ FIX: Create a farm (see above)

PROBLEM 4: "I see red error message"
→ CAUSE: Various (API error, network error, etc.)
→ FIX: Read the error message, it tells you what's wrong

PROBLEM 5: "Dropdown says 'Choose a crop' but won't open"
→ CAUSE: There are no valid crops to show
→ FIX: Create a crop with status "growing"

================================================================================
                      TESTING WITH DATABASE
================================================================================

If you're comfortable with SQL, you can check directly:

CHECK IF YOU HAVE FARMS:
```sql
SELECT * FROM farms WHERE farmer_id = YOUR_USER_ID;
```
Result: Should show at least 1 farm
No result: Create a farm

CHECK IF YOU HAVE CROPS:
```sql
SELECT id, crop_type, status FROM crops 
WHERE farm_id IN (
  SELECT id FROM farms WHERE farmer_id = YOUR_USER_ID
);
```
Result: Should show at least 1 crop
No result: Create a crop

CHECK CROP STATUSES:
```sql
SELECT crop_type, status FROM crops 
WHERE farm_id IN (
  SELECT id FROM farms WHERE farmer_id = YOUR_USER_ID
);
```
Result: Status should be 'growing', 'ready_for_harvest', or 'planted'
Different: Update with:
```sql
UPDATE crops SET status = 'growing' WHERE id = CROP_ID;
```


```bash
cd backend
```

```bash
php artisan config:clear
php artisan migrate
```

Then try Harvest page again
