TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: Email not in inbox
  → Check spam/promotions folder
  → User marks as "Not Spam" in Gmail
  → Verify credentials in .env

Issue: Gmail blocks connection
  → Use App Password instead of regular password
  → Get at: https://myaccount.google.com/apppasswords
  → Update MAIL_PASSWORD in .env
  → Run: php artisan config:cache

Issue: Port 587 blocked
  → Try port 465 instead
  → Update MAIL_PORT=465
  → Update MAIL_ENCRYPTION=ssl
  → Run: php artisan config:cache

Issue: Still not working
  → Check logs: tail -50 storage/logs/laravel.log
  → Read: PRODUCTION_EMAIL_GUIDE.md
  → Read: TECHNICAL_ARCHITECTURE.md
